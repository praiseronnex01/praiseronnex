CASE OVERVIEW

Investigation objective and scope

Case scenario

A sample disk image is used for an educational digital-forensics investigation. The scenario concerns a suspected unauthorised file transfer from a workstation to external storage.

The investigator preserves the evidence, examines relevant artefacts, reconstructs activity and prepares a forensic report.

Investigation scope

  • Verify disk-image integrity
  • Maintain chain of custody
  • Identify files and metadata
  • Review logs and user activity
  • Create an event timeline
  • Document findings and limitations
Legal and ethical notice: Use only a legally obtained forensic training dataset or instructor-authorised sample image. Do not access live systems or private data without proper authority.

Examination procedure

  1. Receive and securely store evidence.
  2. Calculate and record the SHA-256 hash.
  3. Create and verify a working copy.
  4. Load the copy into an appropriate forensic tool.
  5. Review file systems, metadata and logs.
  6. Search relevant keywords and artefacts.
  7. Build a timeline and export supported findings.

INVESTIGATION FINDINGS

Key findings and conclusion

Integrity

Compare actual source and acquired-image hashes.

Files

Record relevant files, paths and metadata.

Timeline

Correlate timestamps and explain time-zone assumptions.

Recovery

Document recovered artefacts and recovery limitations.

Investigative conclusion

Present only conclusions supported by artefacts from the examined training image. Separate direct observations from interpretations, explain alternative explanations and disclose limitations. Do not present sample data as verified evidence.
